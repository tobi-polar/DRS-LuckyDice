# Changelog

## 1.3.2
- Plugin ID is now `tobipolar.drgs.luckydice` (settings carry over from the old file automatically).

## 1.3.1
- New defaults: drops every 25 s at most, Nitra/Gold give 25, Bosco copies turret/drone weapons too, longer/shorter effect durations and rebalanced weights (see the config).

## 1.3.0
- Rapid Fire also gives infinite ammo (no reloading) for its duration.
- New effect: **Infinite Ammo** (no reloading, 15 s).
- Instant effects (Nuke, Nitra, Gold, Biome Minerals, Magnet) are announced in the game's centre-screen banner.
- New effect: **Magnet** (spawns a magnet). Never rolled while Magnet Tweaks is set to AlwaysActive.

## 1.2.0
- Mineral effect is now **Biome Minerals**: 2-8 of one of the current biome's two rich minerals (e.g. Salt Pits: Bismor or Enor Pearl). Amount is fixed by design; the effect is rarer (weight 1).

## 1.1.1
- Bosco Backup no longer copies turret/drone weapons like the LMG Gun Platform (they caused error spam after the effect ended).

## 1.1.0
- First Thunderstore release.
